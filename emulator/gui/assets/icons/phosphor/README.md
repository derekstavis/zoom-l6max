# Solid panel symbols

Unmodified upstream [Phosphor Icons](https://github.com/phosphor-icons/core)
SVG assets, pinned to revision `2b75f3ad12b420c9504ef05df8d2564a28f8500e`.
The upstream MIT license and copyright notice are included in [LICENSE](LICENSE).

Filled speaker, transport and caret symbols approximate the hardware's solid
printed markings. The check symbol uses the bold weight. GPUI embeds and caches
the source SVG bytes, supplying the foreground color at paint time.
