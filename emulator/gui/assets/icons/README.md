# Panel icons

These unmodified SVG assets are from [Lucide](https://lucide.dev/), pinned to
revision `5a92b9ba262de5bf10e864219883267672c05db8` of
[lucide-icons/lucide](https://github.com/lucide-icons/lucide/tree/5a92b9ba262de5bf10e864219883267672c05db8/icons).

The complete upstream license is included in [LICENSE](LICENSE). Lucide uses
the ISC license; icons derived from Feather also carry the MIT license
described in that file.

The native panel embeds these files at compile time and renders them through
GPUI's cached SVG masks. Colors and dimensions are supplied by each control.

Solid speaker, playback and recorder navigation symbols use the separately
licensed [Phosphor assets](phosphor/README.md), which more closely match the
hardware's filled markings.

Solid panel symbols come from [Phosphor](phosphor/README.md), with their own
pinned revision and MIT license. They match the device's filled mute, transport,
and navigation markings more closely than outline symbols.
